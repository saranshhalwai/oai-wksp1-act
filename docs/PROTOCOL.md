# Protocol v1 / rules v1 / physics v1

Attendees implement their own client against the deployed backend. No game SDK or local backend is provided. Start with [BACKEND_CONNECTION.md](BACKEND_CONNECTION.md) for transport setup, state parsing, terrain decoding, timing and recovery. The reference ZIP includes generated BACKEND_TYPES.md and JSON examples.

HTTP matchmaking and WebSocket paths are those generated by Colyseus 0.18. The Caddy default route proxies all non-static paths, including `/matchmake/...` and `/<processId>/<roomId>`. There is no guessed `/ws` endpoint. HTTP is not used to poll gameplay.

All mutations carry `{v,id,matchId,turnId,type,data}`. IDs are 1–80 safe characters; frames ≤16 KiB, command payload ≤2 KiB, 40 messages/second/seat. Create rate is an aggregate 300/minute across campus clients, plus the room cap. Names are ≤24 characters; room codes use six unambiguous characters. No account authentication: the transport seat and reconnect token identify the player. Origin is an additional browser policy, not identity.

| Type | Data |
|---|---|
| ready | boolean |
| aim | `{angle,power,weapon,seq}`; monotonic per-turn revision |
| fire | `{angle,power,weapon}`; final aim snapshot |
| move | `left` or `right` |
| rematch | no payload |
| leave | no payload |

Server `ack` is `{id,ok,error?,serverTime}`. A bounded 256-entry outcome cache returns the original outcome for an identical retry, rejects conflicting IDs, and is scoped by seat. Every input checks match and turn identity. The server does not accept terrain, scores, hit positions or client clocks. Unknown extra fields cannot change server outcomes.

Public synchronized state includes versions/build, room/match/turn, player seats/names/inventory/score/aim/moves, tanks, wind/deadline, terrain version/checksum, phase, history and result. `snapshot` includes packed terrain plus active timeline and server time. `timeline` carries tracks, events, start/duration, base version, final patch and settling targets. `patch` carries the committed removal delta. `ping`/`pong` calibrate time. `server-error` aborts without a winner.

Only one active timeline is retained; reconnect gets committed base plus that timeline. State recovery discards old effects and drafts. Bounded histories retain 20 shots. Waiting rooms expire after ten minutes; room hard lifetime is 45 minutes. Third players and replacement seats are rejected. Restart invalidates all in-memory rooms/tokens.
