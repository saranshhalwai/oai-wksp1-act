# Community and support

Artillery Lab was built for a frontend workshop and is being released for anyone to play, host, and modify. This repository brings together the game, both browser themes, and the server so you can play with friends, explore the code, and make it your own.

Start with the README for local play and [self-hosting guide](docs/SELF_HOSTING.md) for hosting your own matches. Each host runs their own server and manages its availability and updates. The public release is designed for independent hosting; an ongoing shared backend and dedicated technical support are not included.

Community fixes and ideas are welcome through issues and pull requests where enabled. Maintainer responses and updates are best effort. When sharing a problem, include reproduction steps and relevant errors, keeping credentials, player data, and private logs out of public posts.

For connection problems, check the backend health endpoint, the browser origin allowlist, and the server logs using the self-hosting guide.
